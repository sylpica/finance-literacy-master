# FINANCIAL_MODELS.md — 計算式と前提（実装: src/finance/core.ts）

| モデル | 式 | 前提・限界 |
|--------|-----|-----------|
| 将来価値 | FV = PV(1+r)^n | r は期間あたり一定。r > -1 |
| 現在価値 | PV = FV/(1+r)^n | 同上 |
| 年金終価 | PMT×((1+r)^n−1)/r | 期末払い。r=0 は PMT×n |
| 実質金利 | (1+名目)/(1+インフレ)−1 | フィッシャー方程式の厳密形 |
| CAGR | (End/Begin)^(1/years)−1 | 途中変動を捨象した平均成長率 |
| IRR | NPV(r)=0 を二分法で解く | 符号変化が範囲内にある場合のみ。複数解の可能性を教材で明記 |
| 積立シミュレーション | 月次複利＋年末手数料控除 | リターン一定。税は別シミュレーターで扱う |
| 税引後（課税口座簡易） | 元本＋利益×(1−税率)（利益>0のみ） | 配当課税・損益通算は未モデル化と明記 |
| DCF | Σ FCF_t/(1+WACC)^t ＋ TV/(1+WACC)^n, TV=FCF(1+g)/(WACC−g) | WACC>g 必須。仮定感応度を感度表で表示 |
| 配当割引 | P = D1/(r−g) | r>g 必須、定率成長の仮定 |
| CAPM | E[R] = Rf + β(E[Rm]−Rf) | 前提と限界は教材 D-02 で扱う |
| 債券価格 | Σ クーポン/(1+y)^t ＋ 額面/(1+y)^n | 年1回払いの単純化を明記 |
| デュレーション | マコーレー加重平均回収期間、修正 = /(1+y) | 小さな金利変化の近似 |
| ポートフォリオ | μ_p = w'μ, σ²_p = w'Σw | パラメータ既知・安定の仮定を明記 |
| VaR/CVaR | ヒストリカル法（損失分位点／尾部平均） | 分布仮定に依存。VaRは超過損失の大きさを示さない |
| モンテカルロ取り崩し | 年次正規乱数（シード固定）、残高<0で枯渇 | 正規・独立・パラメータ一定の仮定をUIに表示 |
| ブラック・ショールズ | 標準式（ncdfはAbramowitz-Stegun近似、誤差<7.5e-8） | ボラティリティ一定・対数正規等の前提を明記 |
| 清算価格（ロング近似） | Entry×(1 − 1/Lev + 維持証拠金率) | **教材用の近似**。取引所の厳密式ではない |
| 資金調達コスト | 想定元本×レート×期間数 | レート一定の仮定 |
| AMM | out = Rout×in(1−fee)/(Rin＋in(1−fee)) | 定数積型のみ。集中流動性型は対象外 |
| インパーマネントロス | 2√r/(1+r) − 1 | 手数料収入を含まない |
| ヘルスファクター | 担保×清算閾値÷借入 | プロトコル差異は教材 H-04 で扱う |
| ステーキング実効利回り | (1+APR/n)^n − 1 − P(slash)×毀損率 | 期待損失の線形控除は近似と明記 |
| スリッページ推定 | σ×√(注文量/出来高) | square-root law の教材用簡略形 |

検証方法は TESTING.md、各関数の期待値は tests/finance.test.ts（解析解・手計算との照合）。
