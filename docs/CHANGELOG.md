# CHANGELOG.md

## 0.2.0（2026-11-02、洗練フェーズ第1節目）
- 演習問題を112問→224問に拡充（全56教材が4問に）。新規112問は既存2問と実質同一でない別小論点を出題し、計算問題34問は全件独立検算済み。計算ドリル型では数値に加え構造のひねり（配当相殺・取崩し順序の反転・空売り側・マイナスの資金調達率・配分比率変更等）を加えた。構造テストの不変条件を224問・各教材4問に更新
- UI/UXを再設計: デザイントークン（色・角丸・影）と共通コンポーネント（パネル・統計グリッド・状態チップ・進捗バー）を導入し全画面で統一。ホームをダッシュボード化（学習統計・全体進捗・続きから学ぶ・分野別進捗）。教材ページはパンくず・情報チップ・層タブのセグメント化・前後ページャー。演習は進捗バー・選択肢バッジ・結果画面を整備
- 全アプリ共通UIルール（2026-11-02 ユーザー指示）を適用: スクロールを抑え主要操作を一画面側へ、文字の切れを作らない、説明文は画面下部へ配置（ホーム説明文は下部パネルへ、教材ページは本文を目標・用語パネルより前に、制度・分析ページの説明文を下部へ）
- ヘッダーをコンパクト化（同日の追加指示）: 説明文（タグライン）をヘッダーから外し、タイトルとナビを1行に収めて高さを約110px→46pxに削減

## 0.1.1（2026-11-02、品質監査対応）
- 全面自己監査（コンテンツ全件・コード堅牢性・UIハンズオン・シミュレーター数値の独立再検証）を実施し、指摘を修正
- 堅牢性: シミュレーター/ラボの数値入力を共通部品で範囲内に検証（白画面・NaN%表示を解消）、ErrorBoundary追加、DCFで WACC≦永続成長率 の案内表示
- 学習: ランダム演習の出題が偏る不具合を修正、復習モードの読込前表示・未保存回答の破棄を修正
- 保存: バックアップ復元の要素検証、保存の原子化、CSV日付の実在チェック、書込失敗時のメモリ退避
- コンテンツ: 取り崩し前提（期首/期末）の混同解消、担保係数（最大LTV）と清算閾値の区別、教材と同一数値の問題を書き換え、表記統一（全角＝／：・常体・万円）、制度日付の意味分離（effectiveFrom/announcedAt）、出典の具体化（株式税制・iDeCo）
- PWA: 更新方式を自動適用に変更

## 0.1.0（2026-11-02）
- 初版: 14分野56教材（4層構造）・112問の選択式演習（単一/複数正答、誤答理由つき）
- 金融計算エンジン（純粋関数）と15種のシミュレーター
- 株式分析ラボ（財務三表の連動モデル）・暗号資産ラボ（投資前リスク点検）
- 仮想投資ケース4件（判断時点までの情報のみ表示し、根拠・リスクで評価）
- 間隔反復（SM-2系）、習熟度推定、弱点・復習推薦
- IndexedDB保存、JSONバックアップ/復元、市場データCSV取込検証
- 制度情報の構造化データ（NISA・上場株式等の税率・暗号資産の所得区分・iDeCo）
- PWA（オフライン precache）、GitHub Pages向けCI
