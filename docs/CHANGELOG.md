# CHANGELOG.md

## 0.1.1（2026-11-02、品質監査対応）
- 全面自己監査（コンテンツ全件・コード堅牢性・UIハンズオン・シミュレーター数値の独立再検証）を実施し、指摘を修正
- 堅牢性: シミュレーター/ラボの数値入力を共通部品で範囲内に検証（白画面・NaN%表示を解消）、ErrorBoundary追加、DCFで WACC≦永続成長率 の案内表示
- 学習: ランダム演習の出題が偏る不具合を修正、復習モードの読込前表示・未保存回答の破棄を修正
- 保存: バックアップ復元の要素検証、保存の原子化、CSV日付の実在チェック、書込失敗時のメモリ退避
- コンテンツ: 取り崩し前提（期首/期末）の混同解消、担保係数（最大LTV）と清算閾値の区別、教材と同一数値の問題を書き換え、表記統一（全角＝／：・常体・万円）、制度日付の意味分離（effectiveFrom/announcedAt）、出典の具体化（株式税制・iDeCo）
- PWA: 更新方式を自動適用に変更

## 0.1.0（2026-11-02）
- 初版: 14分野56教材（4層構造）・112問の選択式演習（単一/複数正答、誤答理由つき）
- 金融計算エンジン（純粋関数）と15種のシミュレーター

- IndexedDB保存、JSONバックアップ/復元、市場データCSV取込検証
- 制度情報の構造化データ（NISA・上場株式等の税率・暗号資産の所得区分・iDeCo）
- PWA（オフライン precache）、GitHub Pages向けCI
