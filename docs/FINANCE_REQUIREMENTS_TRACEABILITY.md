## 4章 単語帳モード必須仕様

| 要件 | 対応 | 実装・証跡 |
|---|---|---|
| 4.1 カードデータ（校正済み定義、一意の cardId、教材・分野・根拠との対応、問題IDと混ぜない） | 対応 | carddefs.ts（311用語を校正）＋ flashcards.ts（FC- 接頭辞の cardId、lessonId/domainId/level/sources を保持）。詳細は FINANCE_FLASHCARD_SPEC.md |
| 4.1 裏スタート用に答えが透けない設問文を別途保持 | 対応 | cue を定義と別に保持し、用語を含まないことを単体テストで保証 |
| 4.2 表/裏の開始設定（開始前に毎回変更可、保持可、途中切替で履歴を壊さない） | 対応 | localStorage に保持しつつ開始前に毎回変更可能。途中切替は現在のカードのまま表示面が変わる仕様を明記 |
| 4.2 反転はタップ/クリック/Enter/Space、複雑な演出なし | 対応 | role=button＋キーボード対応、反転は瞬時切替（3D演出なし）。prefers-reduced-motion でも遷移なし |
| 4.3 絞り込み（分野/教材/保存のみ/未学習/苦手） | 対応 | 設定画面に実装。0枚時は理由を表示し開始不可 |

| 4.3 保存は裏表どちらからでも即時保存 | 対応 | ☆は反転領域の外に常設し、どちらの面でも操作可能 |
| 4.3 シャッフル/再シャッフル/最初から、集合を失わない | 対応 | 置換性を単体テストで保証。再シャッフルは現在のカードを保持 |
| 4.3 前/次・位置と総数・完了表示・空状態 | 対応 | 実装し E2E で確認 |
| 4.3 自己評価は主観と明示し正答率に見せない | 対応 | FINANCE_FLASHCARD_SPEC.md 4節 |
| 4.3 再読込等でブックマーク保持。進行状況を保持しない設計なら再開手段を明示 | 部分対応 | 保存・自己評価は永続化される。セッションの進行位置は保持しない設計で、再開は設定画面から同じ条件で開始する（方向設定は保持される）。進行位置の永続化は未実装として明記 |
| 4.4 受入テスト (1)〜(9) | 対応（一部代替） | (1)〜(6)(8)(9) は単体・E2E で実施。(7) の200%拡大は未実施で、幅320/375px の狭幅確認で代替した旨を証跡に記録 |

## 5章 問題演習

| 要件 | 対応 | 実装・証跡 |
|---|---|---|
| 5.1 問題ごとのブックマーク（回答前後とも操作可、表示と永続化の一致） | 対応 | quiz-head に☆を常設（回答前後とも操作可）。qbookmarks に永続化し E2E で切替を確認 |
| 5.2 保存した問題のみ＋分野・状態フィルタとの組み合わせ | 対応 | saved モード＋開始前画面で分野／未回答／直近が誤答／復習期限の絞り込み（filterSavedQuestions、単体テスト4件） |
| 5.3 出題順シャッフルON/OFF・再シャッフルを全モードで一貫提供、セッション確定後は揺れない | 対応 | 開始前画面で全モード共通に提供（単一問題モードは対象外として明示）。開始時に出題順を確定し、再シャッフルは未出題分のみ・現在の問題と履歴は不動（E2Eで表示不変を確認） |
| 5.4 選択肢シャッフルの整合（正答ID・誤答理由の対応が崩れない） | 対応 | 決定的シード＋ID採点の既存実装を監査で確認。R2 の回帰テスト群が継続通過 |
| 5.5 検索→その問題へ直接移動、解説→教材・用語へ | 対応 | 単一問題モード（R2実装）に加え、解説後に「単語帳で用語を確認」を追加。シミュレーター導線のみ未実装（3.6参照） |
| 5.6 境界条件のテスト | 対応 | 保存0件・絞り込み0件の空状態、multi 問題を含む既存テスト群、E2E の回答フローで確認 |
| 5.7 初見正答率を水増しできない | 対応 | コード監査で「問題ごとの最早回答のみ・分母=回答済み問題数」を確認 |
| 5.8 模擬試験 | 対象外 | 現行アプリに模試はなく、追加もしていない（指令書の指示どおり） |
